Code¶

Code blocks are sunken wells with a copy button that appears on hover. The Pygments palette follows the runescapecn code sample colours: keywords green, attributes and numbers cyan, strings yellow, comments grey.

Python¶

from dataclasses import dataclass


@dataclass
class Player:
    """A logged-in account."""

    name: str
    combat_level: int = 3

    def greet(self) -> str:
        # Welcome message shown on login.
        return f"Welcome to 2009scape, {self.name}!"

static/js/login.js¶
const login = async (username, password) => {
  const response = await fetch("/api/login", {
    method: "POST",
    body: JSON.stringify({ username, password }),
  });
  return response.json();
};
