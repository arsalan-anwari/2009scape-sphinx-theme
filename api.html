API reference¶

Autodoc output, so the object-description styling has something real to render.

A Sphinx theme with the look and feel of 2009-era RuneScape.

The visual language (palette, pixel fonts, bevelled borders, stone panels) is ported from the runescapecn shadcn registry, which is vendored under vendor/runescapecn in this repository for reference.

sphinx_2009scape_theme.setup(app: Sphinx) → ExtensionMetadata[source]¶

Highlighting¶

Pygments styles matching the 2009scape palette.

The colour choices mirror src/components/code-block.tsx in the runescapecn reference implementation: tags/keywords are RuneScape green, attributes cyan, strings yellow, comments grey-italic and plain text the familiar interface orange.

class sphinx_2009scape_theme.highlighting.Scape2009LightStyle[source]¶

Bases: Style

Parchment-toned variant, used when a light Pygments style is requested.

The theme itself is dark by design, but Sphinx asks for a default Pygments style when a page is rendered with a light user agent stylesheet (and some extensions render snippets on a pale surface).
